# `@cursor/sdk` 1.0.31 compatibility audit

Scope: exact dependency update from 1.0.30 to 1.0.31. This is a package and
contract-test audit, not a live Cursor model receipt.

## Streaming contract

- `dist/esm/vendor/cursor-sdk-shared/delta-types.d.ts` is byte-identical to
  1.0.30. The `InteractionUpdate` union still has no event that marks the end
  of a model generation before local custom tools execute; `turn-ended` remains
  the end of the whole agent turn.
- The core-to-delta adapter (`coreToSdkUpdate`) is unchanged: it maps
  `textDelta`, `thinkingDelta`, `thinkingCompleted`, `userMessageAppended`,
  `tokenDelta`, `summary*`, `shellOutputDelta`, `toolCallStarted`,
  `partialToolCall`, `toolCallCompleted`, `turnEnded`, `toolCallDelta`,
  `stepStarted`, `stepCompleted`, and `promptSuggestion`, and drops only
  `heartbeat`. Upgrading does not change how tool batches close; see
  [the batch-close probe](2026-09-04-tool-batch-close-live-probe.md).

## Public surface delta

- `AgentOptions.systemPrompt` (local agents only, non-empty, not persisted
  across `Agent.resume`, server-side per-account gate that fails the first
  `send` with an `InvalidArgument` naming `--system-prompt`). The gateway uses
  it for `HOST_SYSTEM_PROMPT_MODE=replace`.
- `SDKCustomTool.annotations` (`SDKToolAnnotations`: MCP `Tool.annotations`
  hints, advertised verbatim). Not mapped: none of the protocol IRs carries
  MCP annotations, and the hints are descriptive only.
- Cloud-only `agentServeAgent` and the `SteerAckOutcome` type. Not used by the
  local gateway.
- `Agent.create`, `Agent.resume`, `SDKAgent.send`, `Run.stream`, `Run.wait`,
  `Run.cancel`, `Cursor.models.list`, and `Cursor.me` are unchanged.

## Sand patch contract

The `x-cursor-client-type` sites are in the same files with the same counts as
1.0.30: two in `dist/esm/index.js` (one JSON header literal, one `set(...)`
call) and one in `dist/esm/357.js`. Only the file hashes changed;
[`src/sdk/sand-patch-contract.ts`](../../src/sdk/sand-patch-contract.ts) now
pins the 1.0.31 original and target SHA-256 values. 1.0.30 hashes must not be
reused.

## Verification boundary

The deterministic suite, TypeScript checks, server and console builds, package
lock readback, and diff check cover this update. Live Cursor credentials and
model behavior are outside this audit; the live smoke and timing runners record
them separately.
